Technology Stack & Architecture

Three specialised pipelines working in concert to analyse fetal ultrasound images, retrieve clinical evidence, and generate structured medical reports.

Architecture

Three-Pipeline Processing Architecture

Hover over each pipeline card to expand the full technical detail. Click to pin.

Pipeline 01

Vision Ingestion

Image preprocessing and quality validation

  • OpenCV image decoding & normalisation
  • Pillow RGBA→RGB conversion
  • NumPy array standardisation
  • Acoustic quality scoring (0–10)
  • Artefact & shadowing detection
  • Base64 encoding for API transport
Pipeline 02

Clinical RAG

Hybrid evidence retrieval from three backends

  • SQLite FTS5 full-text keyword search
  • ChromaDB semantic vector similarity
  • OpenAI Vector Store cloud retrieval
  • Top-K chunk fusion & ranking
  • Citation ID tagging [Record X]
  • Context window assembly
Pipeline 03

Multimodal Fusion

GPT-4o Vision report generation

  • GPT-4o Vision multimodal call
  • 3-tier system prompt injection
  • Triage classification (Gravid / Non-Gravid / PUL)
  • 8-part structured report assembly
  • Medico-legal guardrail enforcement
  • Multi-turn conversation support
